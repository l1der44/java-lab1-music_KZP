1. Лабораторна робота № 1: Інфраструктура та базовий прототип
Тема роботи
Налаштування інфраструктури Java-проєкту, використання інструментів автоматизації збірки (Apache Maven), статичного аналізу, CI/CD (GitHub Actions) та розробка базового прототипу обробки вхідних CSV-даних.

Мета
Створити базову структуру репозиторію, налаштувати систему збірки Maven із Wrapper, додати конфігурацію CI у GitHub Actions для тестування на трьох операційних системах (Windows, macOS, Ubuntu) та реалізувати первинне зчитування й фільтрацію даних про музичні треки.

Основні характеристики та модель даних (Лаб № 1)
Збереження даних: запис існував у вигляді рядка CSV або базової структури/record без виділеного класу-сутності.

Валідація: перевірка коректності полів здійснювалася безпосередньо у циклі зчитування файлу MusicManager.java.

Обробка помилок: некоректні рядки відсіювалися простими умовами без збереження номерів рядків чи причин відхилення.

Звітність: базовий розрахунок загальної та середньої тривалості відфільтрованих треків.

Plaintext

2. Лабораторна робота № 2: Рефакторинг, інкапсуляція та модульні тести
Тема роботи
Класи, Record і інкапсуляція в Java-проєкті.

Мета
Перебудувати внутрішню предметну модель продукту з Лабораторної роботи № 1: замість рядкових записів створити клас-сутність 
з інкапсульованим станом, перенести перевірку інваріантів у конструктор, створити статичний фабричний 
метод fromCsv, додати record для підсумкових показників та покрити поведінку тестами JUnit 5.

Основні характеристики та модель даних (Лаб № 2)

Клас-сутність Track.java:
Усі поля приховані модифікаторами private final (незмінний стан).
Відсутні сеттери.
Перевірка інваріантів виконується до присвоєння значень у конструкторі (Objects.requireNonNull, isBlank(), durationSeconds >= 0).
Статичний фабричний метод Track.fromCsv(String line) відповідає за розбір рядка та конвертацію типів.
Допоміжний DurationGenre.java (Record):
Компактний носій статистики (count, totalDuration, averageDuration, maxDuration).
Містить валідацію підсумкових показників.
Оновлений MusicManager.java:
Зберігає список валідних об'єктів Track.
Фіксує помилкові рядки у список errors із зазначенням номера рядка та точного тексту помилки.
Модульні тести TrackTest.java:
Перевіряють створення коректного об'єкта, відхилення null/порожніх рядків, від'ємного часу, помилок формату CSV та рівність записів record.
